The Mask Is Not the Object: Volumetric Supervision for 3D Gaussian Segmentation

Jeonghwan Cho, Minsu Kim, Junyoung Hong, Seon Joo Kim

Yonsei University

Paper soon arXiv soon Code soon Removal-3D soon
TL;DR

3DGS segmentation renders accurate masks but selects an incomplete set of object Gaussians. VODA is a plug-and-play objective whose depth-aware rasterizer supervises every Gaussian in an object's depth cluster directly, and Removal-3D measures whether removing them actually changes the scene in 3D.

Contributions

    Volumetric segmentation

    We formulate the task, showing how an accurate rendered mask can still correspond to a Gaussian set that fails to account for the object in 3D.

  2. 2

    VODA

    A plug-and-play objective that supervises every Gaussian in the selected depth cluster directly, leaving the baseline's representation and inference untouched.

  3. 3

    Removal-3D

    A benchmark and the Removal Depth Error for depth-based removal evaluation, with consistent gains across four baselines.

What has to change

The problem

Supervision is scaled by how much a Gaussian contributes to the render, and that contribution collapses behind the first opaque surface. The interior of an object is never asked to belong to it, so the mask comes out right and the set comes out hollow.

Our take

Choosing the dominant contributor per pixel, or its top-k, still answers which Gaussian explains a pixel. The question worth asking is which Gaussians make up the object, and it belongs along the ray rather than on the image plane.

Key idea

Volumetric supervision. Split each ray where the depth jumps, keep the cluster the object actually occupies, and supervise every Gaussian in it directly, whatever it contributes to the image. Occluded Gaussians inherit the target of the visible ones they sit behind.

VODA turns this into two pieces that attach to an existing baseline: a depth-aware rasterizer and a direct per-Gaussian loss.

Method

Feature gradients are scaled by rendering weight wi = Ti αi, so anything behind the first opaque surface learns almost nothing. VODA splits each ray at depth gaps above an adaptive τ, keeps the cluster with the most contribution, and supervises every Gaussian in it directly.

Analysis

Two questions decide whether the diagnosis holds: which Gaussians VODA actually recovers, and whether a simpler fix would have done the same job.

?

Two things have to hold at once. VODA has to be picking out genuinely low-contribution Gaussians, the ones rendered supervision never reaches, rather than just selecting more of what was already visible. And it has to do that while accuracy goes up, not by trading precision for recall. The first is testable because the two checkpoints share identical geometry and opacity, so every Gaussian's maximum contribution is fixed before either method runs; the second is why mIoU is reported beside mRDE everywhere above.

?

The question underneath is whether this problem is hard at all. The obvious objection is that a low-contribution Gaussian simply needs a bigger gradient. If that were true, VODA would be unnecessary: rescaling the rendered-feature loss that already exists would recover the same Gaussians. So we tried three such fixes, and report every metric each one moves.
